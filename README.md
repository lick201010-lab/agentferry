# AgentFerry

**A closed-source desktop platform for managing multiple AI agents.**

Revisit conversations, understand usage, organize rules and skills, and keep local backups in one place.

[Official website](https://agentferry.app/) · [Official downloads](https://agentferry.app/#download)

## What you can manage

- **Conversations:** browse and search existing histories from supported tools.
- **Usage:** view available usage and quota information across supported agents.
- **Rules and skills:** review and organize Claude and Codex configurations.
- **Backups:** create local backups and portable conversation or environment packages.

Features and migration support vary by agent. Claude quota percentages are estimates. Importing conversations into Codex is experimental.

AgentFerry manages existing histories and agent configuration. It does not provide a shared live-chat composer, automatic agent orchestration, or task scheduling.
